## 1. 背景与定位

- 通用技术协议 PDF 差异比对（激光/卷绕/碟片/涂布/模切/分切等任意设备类型）。
- 处理 CATL 等客户 DLP 加密 PDF（Sangfor ztsm `%TSD-Header-###%`），输出 Markdown 完整版 + HTML 仅差异版（红=A 旧值 / 绿=B 新值）。
- 部署点：`geesun_agent/skills/__user_GY24428__/tech-spec-pdf-diff/`（agent 运行时加载，已入库）；`~/.workbuddy/skills/tech-spec-pdf-diff/`（WorkBuddy 本地副本，**已于 2026-08-20 末期经 cmp 逐字节校验与项目内同步一致**；后续任一副本变更须同步另一副本）。
- 执行方式：提取/机械 diff/报告生成已黑盒化为 MCP 工具 `run_pdf_diff_stage1` / `run_pdf_diff_stage3`，agent 禁止自写替代代码；唯一 LLM 手工步骤是写 `diff.json`（语义判定）。

## 2. 架构三层

| 层 | 谁执行 | 产物 | 性质 |
|---|---|---|---|
| ① 提取+结构定位 | Python 脚本（stage1） | docA.json / docB.json / diff_pages.json | 确定性 |
| ② 语义判定 | LLM（唯一手工步骤） | diff.json | 约束下的模型判断 |
| ③ 报告渲染 | Python 脚本（stage3） | .md / .html | 确定性 |

## 4. 边界场景与设计决策（2026-08-20 复盘确定）

| 场景 | 问题 | 设计决策 |
|---|---|---|
| S1 跨页拉长 | A p20 ≈ B p21，且 B 该章延伸到 p25 | 对齐单元不用"页"，用**章节/条款块**，块文本比对天然兼容页数不同 |
| S2 标题不同内容相同（≥90%） | 标题改措辞，正文几乎没变 | 对齐度量用**内容相似度**，标题仅辅助信号，报告落"标题变更+内容一致" |
| S3 章节内容拆散到 B 多章 | A 一章的条款散到 B 多个章节 | 对齐单元降到**条款级**（sections），LCS 允许跨章节匹配（保持相对顺序），章节状态由条款映射**聚合推导** |
| S4 位置 1:1 cascade | 插入/删除后后续页/章全标差异 | 内容感知对齐（LCS 归位）从源头消除；章节状态=条款映射聚合，不再直接比标题 |

核心原则：**对齐单元=条款；相似度度量=内容；匹配算法=带顺序约束的 LCS（支持 1:N / N:1 / 跨章）；章节状态=聚合推导；页只是展示坐标。**
